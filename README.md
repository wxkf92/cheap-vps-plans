## 4837 和 9929 的差别，值不值每月 3 澳元

4837 走联通骨干网出口，9929 是联通精品网线路。两者都是回程优化，页面上 9929 那两款额外标了“直播无需中转”。

便宜境外机最容易出问题的地方就在这里。业内大量低价方案用的是普通国际带宽，白天测速漂亮，晚上八九点国内出口拥塞时丢包率飙升、延迟冲到 200ms 以上，做直播推流会直接卡成幻灯片。4837 和 9929 属于把这个环节往上提了一档，9929 在高峰期通常更稳一些。

页面没有公布任何国内 ping 实测值。线路名称不等于延迟数字，4837 也可能在你所在的省份表现一般，9929 也不会让洛杉矶变成亚洲节点。想验证只能自己买最便宜那档跑一晚高峰期的测试。

多花的钱很少：AUD$12.90 到 AUD$15.90，每月 3 澳元，一年 36 澳元。用它换一条高峰期的稳定回程，做直播和账号运营的人基本不用犹豫。只是跑脚本、拉数据、挂个轻量服务，这笔钱可以省。

## 1.5TB 和 1000GB 到底是多少，限速之后会怎样

按 30 天算，1.5TB 平均每天约 51GB，1000GB 约 33GB。做 TikTok 视频上传、直播推流、批量素材同步，这个量不算宽裕，一天几十条高清视频就能吃掉大半。

超量之后页面写的是“限速 3M”（英国 TikTok 专用是 5M），没有写停机，也没有写可以加购流量包。3Mbps 大概就是能维持连接、跑不动视频的水平。如果你的业务量会持续超过 1.5TB，得先开工单问清楚超量后的处理方式和是否有加量选项，别等到月中被限速才发现。

英国原生家宽那款写的是“1.5TB 双向”，上传和下载都计入额度。同样标 1.5TB，双向计费的实际可用量比单向少一半，做直播推流这种上传吃重的场景，这个差别很实在。

再说结算。全部价格是澳元，人民币卡扣款按发卡行当日汇率折算，可能还有货币转换费。AUD$12.90 折成人民币在六十元档，具体金额看你银行怎么算，别按标价直接当人民币预算。

## 哪些人不该买 WePC

**要用 shadowsocks 的**。页面上明确写着“严禁使用 shadowsocks 协议”，这条放在最显眼的位置。搜便宜 VPS 的人里有相当一部分就是冲着这个来的，看到这里可以直接关掉页面了。违反之后怎么处理页面没写，但规则摆在那，别拿账号赌。

**要求 SLA 承诺的**。页面没有任何 SLA 数字或可用性承诺，也没有公开的退款条款和试用政策。这意味着买之前你得自己开工单问清楚：不合适能不能退、退多少、多久到账。没问就付钱，出问题时没有文本依据。

**流量吃紧的大带宽业务**。1.5TB 加 3M 限速的组合，跑视频分发、CDN 回源、大文件同步会很难受。

**要亚洲节点的**。现有页面只有美国和英国两个方向，香港、日本、新加坡都没有。

## 常见问题

**0.5GB 内存能跑什么？**
轻量代理、单一小服务、定时脚本、监控探针这类。装带面板的完整环境（宝塔 + MySQL + PHP）会频繁 OOM，512MB 的机器同理。

**流量用超了会直接停机吗？**
页面写的是“超流量限速”，美国款限到 3M、英国 TikTok 专用限到 5M，不是断网。限速期间基本只能维持连接。

**AUD$12.90 和 AUD$15.90 差在哪？**
线路等级。前者 4837 三网优化，后者 9929 高级线路回程优化，另外都标了双 ISP。配置几乎一样，都是 2 核 512MB（洛杉矶款是 1 核）。

**价格是人民币吗？**
不是，全部按澳元计价，人民币金额由发卡行按汇率折算。

**能装 Windows 吗？**
页面只提到 Linux 环境下的 BBR 设置，没有列出可选系统镜像。需要特定系统的话下单前问客服确认。
